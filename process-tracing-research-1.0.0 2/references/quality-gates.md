# Quality gates

Run automated checks first, then conduct the substantive review below. A pass means “no detected problem,” not “causal truth established.”

## Gate A — question and design

- [ ] Outcome, case, and time boundary are explicit.
- [ ] Primary process-tracing variant matches the inferential aim.
- [ ] C and O are not hidden inside each other's definitions.
- [ ] Case selection follows the variant and acknowledges access.
- [ ] Prior and conclusion ceiling are stated before focal evidence, or an already evidence-aware task is explicitly labeled `retrospective prior reconstruction`/`evidence-aware discovery` with excluded information and sensitivity stated.

Blocking failures: undefined outcome; theory test in a case where C or O is absent without a revision rationale; explaining-outcome claims population generalization.

## Gate B — mechanism

- [ ] Each step has entity, activity, input, output, context, and timing.
- [ ] Each step names the object changed and its state before and after the activity.
- [ ] Productive continuity connects every adjacent step.
- [ ] Necessary/bottleneck steps are identified.
- [ ] Every step has at least one proposition and a disconfirming observation.
- [ ] Discovery and validation evidence are distinguished.

Blocking failures: arrow-only link; outcome restated as mechanism; unsupported necessary step hidden by averaging.

## Gate C — cases and time

- [ ] Population and case type are documented.
- [ ] Start/end and expected lags are justified.
- [ ] Post-outcome statements are marked as retrospective.
- [ ] Rival temporal predictions are considered.
- [ ] Mechanism-heterogeneity risks are recorded.

Blocking failures: impossible temporal order; case selected only on outcome and vivid evidence; chronology treated as transmission.

## Gate D — sources

- [ ] Every factual claim links to inspected content and locator.
- [ ] Access state is recorded.
- [ ] Authenticity, proximity, competence, and motive are assessed.
- [ ] Source families reveal copying/shared informants.
- [ ] Missing-evidence searches document access probability.
- [ ] Prompt-stipulated observations are marked `stipulated` and remain conditional rather than source-verified.

Blocking failures: fabricated locator; detail supported only by metadata/snippet; dependent reports counted as independent; confidential or unlawful use.

## Gate E — evidence and updating

- [ ] Theoretical certainty and uniqueness are separate.
- [ ] Empirical meaning, reliability, uniqueness, and access are separate.
- [ ] Each update compares focal and best alternative likelihoods.
- [ ] Reliability and dependence adjustments are transparent.
- [ ] Aggregation proceeds observation → proposition → step → mechanism.
- [ ] Numerical inputs have elicitation and sensitivity analysis, or qualitative levels are used.

Blocking failures: test label substitutes for reasoning; missing inaccessible record treated as disconfirmation; exact posterior from invented probabilities.

## Gate F — alternatives and counterfactuals

- [ ] At least one genuine rival is mechanistically specified.
- [ ] Evidence-generation alternatives are assessed.
- [ ] Compatible mechanisms are not falsely treated as mutually exclusive.
- [ ] Counterfactual antecedents are minimal and historically possible.
- [ ] “Ruled out” language is supported by incompatibility and strong evidence.

Blocking failures: straw rival; focal confirmation treated as rival falsification; free-form alternative history.

## Gate G — writing and visuals

- [ ] Analysis paragraphs connect theory, action, evidence, transmission, rival, and update.
- [ ] Narrative background is proportionate.
- [ ] Claims preserve uncertainty and source limits.
- [ ] Figures/tables use registered IDs and agree with prose.
- [ ] Captions state limits.

Blocking failures: prose conclusion exceeds claim register; figure shows an unsupported edge as established; source caveat removed from final narrative.

## Gate H — contribution and generalization

- [ ] Contribution changes mechanism, condition, evidence, sequence, or explanation—not just terminology.
- [ ] Scope conditions are explicit.
- [ ] Single-case operation is not presented as population frequency or average effect.
- [ ] Outward generalization names the next cases and varied context.
- [ ] Negative or mixed evidence remains visible.

## Conclusion ceiling

Set the highest permitted conclusion:

| Evidence state | Ceiling |
|---|---|
| Design only; no case evidence | Plausible mechanism and evidence plan |
| Some observations; source/step gaps | Preliminary bounded inference |
| Every necessary step supported; rivals partly open | Supported mechanism in this case |
| Strong, independent evidence; genuine rivals adjudicated | Strong support in this case |
| Repeated tracing across varied contexts | Bounded cross-case generalization |

Never jump a row because the narrative is compelling.

## Audit report format

Report:

1. blocking errors;
2. nonblocking warnings;
3. passed checks;
4. conclusion ceiling;
5. highest-priority missing evidence;
6. revisions made;
7. remaining disagreements or uncertainty.
