# Mechanisms and observables

## Mechanism grammar

A mechanism step has this grammar:

> Under context K and after input I, entity N performs activity V, changing a named object from state A to state B or transmitting specified information/resources/constraints to produce output O within time T, enabling the next step.

Use explicit entities and verbs. Check that the output of step *n* can be the input of step *n+1*. If not, the claimed continuity is missing.

Mechanism building blocks may be structural, institutional, ideational, psychological, or combined. When combining them, write a bridging proposition explaining interaction; do not place incompatible actor assumptions side by side.

## From concept to mechanism

For C and O, isolate the attributes causally relevant to the process. Avoid symmetric definitions when only the positive pole can trigger an activity. Specify thresholds qualitatively if precise measurement is impossible.

Example of insufficient specification:

> International pressure → persuasion → compliance.

Better structure:

1. named external actors transmit a costly, credible demand to a decision-making audience;
2. audience members update beliefs about feasibility or legitimacy under specified access conditions;
3. changed beliefs alter coalition behavior in a decision forum;
4. coalition action changes the authoritative output.

The example is only a grammar. A real project must derive entities, activities, and context from its theory and sources.

## Observable propositions

For each step create one or more nonoverlapping propositions. A proposition predicts a fingerprint, not a source quotation.

Complete:

- `P-*`: If activity ___ occurred under ___, then by ___ we should observe ___ in/through ___ because ___.
- Certainty: occurrence of the activity makes the fingerprint `low/medium/high` likely because ___.
- Uniqueness: absence of the activity makes the fingerprint `low/medium/high` likely because ___.
- Alternative generators: ___ could create the same observation.
- Disconfirmation: if ___ is not found despite access ___, or if ___ is found, confidence falls because ___.

Use multiple independent propositions when a single trace is fragile. Avoid overlapping propositions that count the same act repeatedly.

## Four evidence forms

- **Pattern:** a distribution or configuration across actors, documents, places, or decisions.
- **Sequence:** timing/order inconsistent or consistent with a process.
- **Trace:** a material or documentary residue of an activity.
- **Account:** a participant or observer's description of actions or reasoning.

Forms do not have fixed evidentiary strength. A precise trace may be forged; an account may be uniquely credible; a sequence may fit many explanations.

## Case-sensitive operationalization

Operationalize only after a case is selected. The same mechanism may leave different traces under different secrecy, institutional, media, or archival conditions.

For every proposition identify:

- likely actor and record creator;
- institutional venue;
- expected date window;
- source genre and archive/database;
- preservation/access probability;
- language, code words, and euphemisms;
- what rival explanations predict in the same record.

## Absence and silence

Silence can be evidence only if:

1. the activity should have produced a record;
2. the record creator would have captured it;
3. the record survives and is accessible;
4. search terms and locations were adequate;
5. censorship, secrecy, euphemism, and selective release are considered.

Distinguish `not present`, `not recorded`, `not preserved`, `not released`, `not searched`, and `not found`. Only the first is an empirical state; the others are observation-process states.

## Mechanism completeness test

A step passes only if it has:

- entity and activity;
- input and output;
- the object and direction of change;
- context and timing;
- proposition and predicted fingerprint;
- alternative generator;
- disconfirming observation;
- source target;
- link to next step or outcome.

The mechanism passes only if every necessary step passes or the conclusion explicitly excludes the unsupported step. More evidence for step 1 cannot compensate for missing step 3.

## Discovery and validation

Theory-building is abductive, not pure induction. When an unexpected observation suggests a mechanism:

1. log it as discovery evidence;
2. construct the mechanism and rival explanations;
3. derive new, nonoverlapping fingerprints not used to invent it;
4. seek independent sources or another case;
5. disclose the iteration.

This prevents a discovered clue from being presented as if it were a preregistered prediction.
