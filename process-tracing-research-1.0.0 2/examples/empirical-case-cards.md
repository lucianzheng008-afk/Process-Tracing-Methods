# 经核验的实证案例卡

这些案例卡用于选择范例和训练问题，不是对原研究的替代摘要。元数据与方法用途已通过 DOI、出版社页面或开放补充材料核验；任何详细事实、引文或页码必须回到原文。

## 1. Tannenwald：核禁忌与核不使用

- 原文：Tannenwald 1999, https://doi.org/10.1162/002081899550959。
- 主题：美国在 1945 年后若干情境中的核不使用及规范基础。
- 方法用途：minimalist 理论检验；区分公开/回忆性规范话语与内部最高层记录；演示为什么强证据可能只支持较窄命题。
- 教学警示：确认“规范被感知”不等于证明规范独自决定不使用。完整示范见 `full-worked-example-tannenwald.md`。

## 2. Schimmelfennig：欧盟东扩中的修辞行动

- 原文：Schimmelfennig 2001, https://doi.org/10.1162/002081801551414。
- 主题：欧盟为何启动中东欧入盟谈判；理性政府间主义能解释许多偏好和谈判特征，却不足以解释最终开放谈判。
- 机制：支持扩大的一方战略性使用欧洲共同体的自由规范，使物质议价能力更强的反对者陷入“共同体陷阱”，逐步让步。
- 方法用途：把“规范影响”拆成行动者、论证活动、既有承诺、羞耻/正当性成本与让步；同时与物质议价解释比较。
- 需要回原文核验：谁在何时提出什么论证、内部与公开材料的关系、反对者偏好变化还是策略让步。

## 3. Löblová：认识共同体何时影响政策

- 原文：Löblová 2018, https://doi.org/10.1111/psj.12213。
- 主题：波兰与捷克的健康技术评估认识共同体为何产生不同政策影响。
- 机制骨架：共同体形成 → 能力建设与传播 → 渗透决策结构和/或提供学习 → 决策者偏好/评估变化 → 政策采纳。
- 方法用途：典型案例与偏离案例结合；先在成功案例追踪，再在失败案例定位机制断裂，并把“政策制定者对专业知识的需求”识别为条件候选。
- 教学警示：大量会议、培训和出版物可以证明传播活动，却未必能证明决策者被说服。

## 4. Slater 与 Wong：强势执政党为何让渡权力

- 原文：Slater and Wong 2013, https://doi.org/10.1017/S1537592713002090。
- 主题：发展型亚洲的强势执政党为何可能选择民主化让步。
- 方法用途：比较政治中的理论—案例迭代；可用于设计“高信心让渡”机制的行动者预期、威胁评估、组织能力与时机证据。
- 教学警示：政党强大与民主化先后出现不足以证明“强大导致让渡”；需要追踪精英如何评估风险并把组织实力转化为安全退场预期。

## 5. Allison 与 Zelikow：古巴导弹危机的结果解释

- 原文：Allison and Zelikow 1999, *Essence of Decision*。
- 主题：解释苏联部署、美国封锁与苏联撤回等危机结果的多个面向。
- 方法用途：explaining-outcome；理性行动者、组织过程与政府政治三种镜头互补，用于构建特定历史结果的 minimally sufficient explanation。
- 教学警示：分析折衷不是“什么都算”。不同机制必须有兼容的假设、明确解释对象和独立证据。

## 6. Ricks 与 Liu：四个研究设计教学应用

- 方法原文：Ricks and Liu 2018, https://doi.org/10.1017/S1049096518000975。
- 开放补充材料列出四项应用：日本发展型国家、泰国政党政治、新加坡英语标准化、菲律宾灌溉官僚改革。
- 方法用途：演示从竞争假设、时间线、因果图、替代选择、反事实到焦点与竞争解释证据的设计步骤。
- 重要反例：对 Johnson 的日本发展型国家研究重构指出，极其详尽的历史仍可能因为没有可检验竞争假设、反事实和证据权重而不足以完成理论检验。
- 重要正例：泰国 Thai Rak Thai 案把 Thaksin 个人资源解释与 1997 年宪法制度解释并列，最后保留二者共同作用/多因一果的可能，而不是强迫选出唯一胜者。
- 补充材料：https://static.cambridge.org/content/id/urn%3Acambridge.org%3Aid%3Aarticle%3AS1049096518000975/resource/name/S1049096518000975sup001.pdf。

## 7. Weaver/Wang：从结果的细节特征检验中间因果链

- 方法重构：Wang 2026, https://doi.org/10.1177/00483931261441189。
- 被分析研究：Weaver 关于 1960 年代美国犯罪政策的 “frontlash” 机制。
- 方法用途：把政策内容、时机和推动者身份等结果细节，当作不同中间因果关系在核心与替代解释下的差异化后果。
- 前沿意义：提醒研究者不能只确认中介事件按顺序出现，还要问每条中间边为什么是因果性的。
- 使用限制：这是 2026 年提出的补充性方案，应与来源批判、机制指纹和比较/反事实证据结合，不应取代成熟的全流程框架。

## 按研究目的选案例

| 目的 | 首选案例 | 要学习的动作 |
|---|---|---|
| 规范机制与来源分级 | Tannenwald | 将内部记录、公开话语和回忆录分层 |
| 修辞行动与策略性规范使用 | Schimmelfennig | 比较偏好、论证、承诺与让步 |
| 理论修正/机制断裂 | Löblová | 典型—偏离配对并定位断点 |
| 多案例精英选择 | Slater/Wong | 把组织强度转化为认知和选择机制 |
| 单一历史结果的充分解释 | Allison/Zelikow | 组合互补机制而不虚假简化 |
| 教学型研究设计 | Ricks/Liu | 时间线、因果图、反事实与竞争证据 |
| 中间因果边的前沿检验 | Weaver/Wang | 用结果细节比较边级预测 |
